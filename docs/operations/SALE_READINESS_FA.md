# گیت عرضه عمومی HRing

این سند اجرای `prgold` را قابل‌پیگیری می‌کند. تا زمانی که همه گیت‌ها با شاهد واقعی پاس نشده‌اند، پیام عمومی محصول فقط «نسخه آزمایشی فعال است؛ برای تست ثبت‌نام کنید» است.

## گیت ۱ — قابلیت‌های وعده‌داده‌شده
- [x] Smart Ad، پروفایل شغلی، Interview Kit، Onboarding، Salary و Dashboard در CI پوشش دارند.
- [x] Learning Path و Labor Complaint دارای قرارداد JSON پایدار و مسیر native هستند.
- [ ] Legal Defense باید به job غیرهمزمان با وضعیت، progress، timeout و refund قابل‌پیگیری تبدیل شود.
- [ ] برای هر قابلیت، یک UAT واقعی production با دادهٔ ساختگی و ثبت هزینه انجام شود.

## گیت ۲ — خروجی قابل‌اعتماد
- [x] اطلاعات تماس پشتیبانی فقط از CMS خوانده می‌شود.
- [x] Legal Advisor در نبود منبع، پاسخ مستند جعلی تولید نمی‌کند.
- [x] نام شرکت در Smart Ad بدون بازنویسی مدل حفظ می‌شود.
- [x] placeholderهای Onboarding از دادهٔ واقعی فرم پر می‌شوند.
- [ ] تصویر Smart Ad در MinIO ذخیره و از history با URL خصوصی قابل بازیابی شود.

## گیت ۳ — بسته و اعتبار
- [x] rate card سروری و نمایش هزینهٔ عملیات‌های اصلاح‌شده وجود دارد.
- [ ] نرخ/محدودیت بسته‌های فردی و سازمانی باید توسط مالک محصول تأیید و در پنل اعمال شود.
- [ ] سناریوی پایان اعتبار و پایان دورهٔ اشتراک باید UAT شود.

## گیت ۴ — خرید تا تحویل
- [ ] درگاه پرداخت تأییدشده، webhook و دریافت شناسهٔ تراکنش لازم است.
- [ ] تست خرید sandbox/واقعی: پرداخت، فاکتور، فعال‌سازی، کسر اعتبار، تمدید و refund.
- [ ] در صورت خطا، هیچ اعتبار یا اشتراک نیمه‌کاره نباید باقی بماند.

## گیت ۵ — امنیت
- [ ] آزمون امنیت مجاز روی حساب، سازمان، ادمین، فایل و API با گزارش بازتولیدپذیر.
- [ ] رفع موارد اولویت‌دار `prsec` و بازبینی پس از رفع.

## گیت ۶ — سفر مشتری
- [ ] UAT موبایل و دسکتاپ: ثبت‌نام ← خرید ← استفاده ← history ← پشتیبانی.
- [ ] بررسی RTL، دسترس‌پذیری، خطای قابل‌فهم و refresh/idempotency.

## گیت ۷ — ملزومات فروش
- [ ] متن حقوقی تأییدشده: شرایط استفاده، حریم خصوصی و بازگشت وجه.
- [ ] راه تماس مالک/پشتیبانی در CMS تأیید شود.
- [ ] Search Console و baseline سرعت ثبت شود.

## خروج از گیت
برای هر مربع باز باید تاریخ، محیط، شناسه تست/تراکنش و نتیجه ثبت شود. CI سبز به‌تنهایی شاهد خروج از گیت نیست.
