# همگام‌سازی منابع حقوقی HRing

مشاور حقوقی فقط از متن‌های ایندکس‌شده پاسخ می‌دهد. منبع برخط فعلی، متن تنقیحی قانون کار، قانون تامین اجتماعی و فهرست تازه‌ترین آرای هیات عمومی دیوان عدالت اداری را دریافت می‌کند. هر تغییر محتوا با checksum تشخیص داده می‌شود؛ نسخه قبلی حذف نمی‌شود و با وضعیت `superseded` برای ردگیری باقی می‌ماند.

منبع دریافت خودکار یک آینه حقوقی عمومی است. لینک دقیق همان صفحه در پاسخ کاربر نمایش داده می‌شود. برای اقدام قضایی حساس، متن باید با [سامانه ملی قوانین و مقررات](https://qavanin.ir/) یا [پایگاه ملی اطلاع‌رسانی قوانین و مقررات](https://dotic.ir/) تطبیق داده شود.

## راه‌اندازی و بارگذاری اولیه

```bash
docker compose --env-file .env.standalone -f compose.yaml up -d --build api worker scheduler web
docker compose --env-file .env.standalone -f compose.yaml exec -T worker \
  celery --app=hring_api.worker.app:celery_app call hring.legal.sync_sources \
  --queue=hring.maintenance
docker compose --env-file .env.standalone -f compose.yaml logs --since=10m worker scheduler
```

دستور دوم فقط کار را در صف قرار می‌دهد. پایان موفق باید در log کارگر با نام `hring.legal.sync_sources` و وضعیت `succeeded` دیده شود. نخستین اجرا ممکن است چند دقیقه طول بکشد، چون فاصله خزش اعلام‌شده منبع رعایت می‌شود.

سرویس `scheduler` هر روز ساعت ۰۰:۰۰ UTC همگام‌سازی را اجرا می‌کند. اجرای تکراری ایمن است و برای متن بدون تغییر نسخه جدید نمی‌سازد.

## کنترل پس از استقرار

1. در پنل مدیریت منابع حقوقی، وجود حداقل یک منبع فعال در هر سه دسته `labor_law`، `social_security` و `court_rulings` را بررسی کنید.
2. یک پرسش بدون فایل درباره ماده مشخص قانون کار بپرسید.
3. پاسخ باید حداقل یک ارجاع مانند `[1]` و زیر پاسخ، عنوان منبع، ماده، نسخه و لینک قابل بازشدن داشته باشد.
4. اگر منبع مرتبط پیدا نشد یا مدل ارجاع معتبر نداد، پاسخ باید رد شود و اعتبار رزروشده بازگردد.

## توقف و rollback

```bash
docker compose --env-file .env.standalone -f compose.yaml stop scheduler
```

توقف scheduler منابع فعال موجود را حذف نمی‌کند. برای rollback کامل کد، نسخه قبلی برنامه را deploy کنید؛ داده‌های نسخه‌بندی‌شده سازگار باقی می‌مانند و migration جدیدی وجود ندارد.
